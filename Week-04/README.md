# NetworkWalks - Week 4: VAPT & PDF Password Recovery

This repository contains the deliverables, detailed security assessment report, and proof-of-concept (PoC) evidence for **Week 4** of the NetworkWalks cybersecurity training program.


## 🛡️ Key Deliverables

### 1. Mediroza VAPT Assessment
* **Report:** [`NetworkWalks_Mediroza_Detailed_VAPT_Report.pdf`](./NetworkWalks_Mediroza_Detailed_VAPT_Report.pdf)
* **Overview:** A comprehensive Vulnerability Assessment and Penetration Testing (VAPT) report detailing identified security flaws, risk ratings, exploitation paths, and actionable remediation steps for the Mediroza target environment.

### 2. PDF Password Recovery (Cryptanalysis / Cracking)
* **Evidence:** Located in the [`Evidence/`](./Evidence/) directory.
* **Overview:** Practical demonstration of recovering passwords from encrypted PDF documents (`pdf-1`, `pdf-2`, and `pdf-3`) using password-cracking methodologies and hash extraction techniques.

## ⚠️ Disclaimer
*All testing, password recovery, and vulnerability assessments documented in this repository were conducted strictly within authorized lab environments for educational and training purposes.*
